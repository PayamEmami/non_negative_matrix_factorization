4  NMF on leukemia gene expression data

These exercises apply non-negative matrix factorization (NMF) to the acute leukemia gene expression dataset studied by Golub et al. (1999) and Brunet et al. (2004). The dataset contains 38 bone-marrow samples and measurements for 5,000 genes. Each sample is labelled as acute lymphoblastic leukemia (ALL) or acute myeloid leukemia (AML). The ALL samples are further divided into B-cell and T-cell subtypes.

The labels will not be supplied to NMF. They will be used only after fitting to help interpret the components.

ImportantHow to complete this chapter

Choose either R or Python and use that language throughout the chapter. Run only the code in your chosen tab.

The exercises form one sequential analysis. Keep the same session open as you work. Every exercise begins by listing the objects it requires and ends with a checkpoint listing the objects needed later.

4.1 NMF notation used in the exercises

The expression matrix is arranged with samples in rows and genes in columns:

\[ X \in \mathbb{R}_{\geq 0}^{38 \times 5000}. \]

At rank \(k\), NMF approximates this matrix as

\[ X \approx WH, \]

where

\[ W \in \mathbb{R}_{\geq 0}^{38 \times k} \qquad\text{and}\qquad H \in \mathbb{R}_{\geq 0}^{k \times 5000}. \]

  • A row of \(W\) contains the component scores for one sample.
  • A row of \(H\) contains the gene profile for one component.
  • The product \(WH\) is the reconstructed expression matrix.

4.3 Exercise 2. Examine reconstruction error across ranks

Starting object: X

Goal: Determine what training reconstruction error can and cannot tell us about the NMF rank.

For a fitted reconstruction \(\widehat X=WH\), the root mean squared reconstruction error is

\[ \operatorname{RMSE} = \sqrt{\frac{1}{np}\sum_{i=1}^{n}\sum_{j=1}^{p} (X_{ij}-\widehat X_{ij})^2}. \]

Task.

  1. Fit NMF at ranks 2 through 8 using the full 5,000-gene matrix.
  2. Store the RMSE at each rank in rank_rmse.
  3. Plot RMSE against rank.
  4. Decide whether the rank with the lowest training RMSE must be the most useful rank.
NoteSolution
  • R
  • Python
library(NNLM)

candidate_ranks <- 2:8
rank_rmse <- numeric(length(candidate_ranks))

for (i in seq_along(candidate_ranks)) {
  k <- candidate_ranks[i]
  set.seed(100 + k)
  rank_fit <- nnmf(
    X,
    k = k,
    method = "scd",
    loss = "mse",
    max.iter = 1000,
    rel.tol = 1e-4,
    verbose = 0
  )
  X_rank_hat <- rank_fit$W %*% rank_fit$H
  rank_rmse[i] <- sqrt(mean((X - X_rank_hat)^2))
}

round(rank_rmse, 1)

  candidate_ranks,

  type = "b",
  xlab = "Rank k",
  ylab = "Training RMSE"

The observed RMSE decreases smoothly from about 601 at rank 2 to about 410 at rank 8. The best achievable training error cannot increase when extra components are available, although an individual non-convex optimization run can occasionally return a poorer local solution. Consequently, the lowest training error in this sweep is not sufficient evidence that rank 8 is the most stable or interpretable choice.

4.4 Exercise 3. Choose a rank using consensus stability

Starting objects: X, group

Goal: Evaluate whether sample assignments are reproducible across repeated NMF fits.

Running NMF from different random initializations can produce different sample assignments. For one rank, define a connectivity matrix for each run:

\[ C_{ij}^{(b)}= \begin{cases} 1, & \text{if samples }i\text{ and }j\text{ have the same dominant component},\\ 0, & \text{otherwise.} \end{cases} \]

The consensus matrix is the average of these connectivity matrices across runs. Its entries lie between 0 and 1. Values near 1 mean that a pair of samples is repeatedly assigned together. Values near 0 mean that the pair is repeatedly separated. A clear block pattern indicates stable assignments. Cophenetic correlation summarizes how clearly the consensus matrix supports a hierarchical grouping. Values closer to 1 indicate a clearer structure.

Repeated fits are slower than a single fit. For this exercise only, use the 1,000 genes with the largest variance across samples. The filter must be calculated without using group.

Task.

  2. For ranks 2 through 6, run 15 NMF fits with different random initializations.
  3. Store the cophenetic correlations as cophenetic_by_rank.
  4. Store the rank-2 and rank-3 consensus matrices as consensus_k2 and consensus_k3.
  5. Compare the correlations and consensus matrices, then store the selected rank as chosen_rank.

scikit-learn fits NMF but does not construct a consensus survey automatically. The supplied function below performs the repeated fits and returns the consensus matrix and cophenetic correlation for every candidate rank.

from scipy.cluster.hierarchy import cophenet, linkage
from scipy.spatial.distance import squareform
from sklearn.decomposition import NMF


def nmf_consensus_survey(X, ranks, n_runs=15, seed=123):
    """Calculate NMF consensus matrices and cophenetic correlations.

    X must have samples in rows and features in columns.
    The returned dictionary is indexed by rank.
    """
    results = {}
    n_samples = X.shape[0]

    for k in ranks:
        # Count how often every pair of samples is assigned together.
        same_component = np.zeros((n_samples, n_samples))

        for run in range(n_runs):
            model = NMF(
                n_components=k,
                init="random",
                solver="mu",
                beta_loss="kullback-leibler",
                max_iter=500,
                tol=1e-4,
                random_state=seed + run,
            )
            W_run = model.fit_transform(X)
            labels = W_run.argmax(axis=1)
            same_component += labels[:, None] == labels[None, :]

        # Convert the counts to proportions between 0 and 1.
        consensus = same_component / n_runs

        # Convert consensus similarity to a distance and summarize it.
        distance = squareform(1 - consensus, checks=False)
        tree = linkage(distance, method="average")
        cophenetic = cophenet(tree, distance)[0]

        results[k] = {
            "consensus": consensus,
            "cophenetic": cophenetic,
        }

    return results
gene_variance = X.var(axis=0)
selected_genes = np.argsort(gene_variance)[::-1][:1000]
X_filtered = X[:, selected_genes]

survey = nmf_consensus_survey(
    X_filtered,
    ranks=range(2, 7),
    n_runs=15,
    seed=123,
)

cophenetic_by_rank = pd.Series({
    k: survey[k]["cophenetic"] for k in survey
})
consensus_k2 = survey[2]["consensus"]
consensus_k3 = survey[3]["consensus"]

4.5 Exercise 4. Fit the final model and fix its scale

Starting objects: X, chosen_rank

Goal: Fit the rank-3 model once and put its components on a defined, comparable scale.

NMF has a scaling ambiguity. For any positive diagonal matrix \(D\),

\[ WH=(WD)(D^{-1}H). \]

Consequently, raw columns of \(W\) need not be directly comparable. We will impose one convention: every row of \(H\) will sum to 1. Define

\[ s_r=\sum_j H_{rj}, \qquad H^{*}_{rj}=\frac{H_{rj}}{s_r}, \qquad W^{*}_{ir}=W_{ir}s_r. \]

This changes the factor scales but leaves the reconstruction unchanged:

\[ W^{*}H^{*}=WH. \]

Task.

  1. Fit NMF at chosen_rank using the full 5,000-gene matrix.
  2. Store the direct model output as W_raw and H_raw.
  3. Store the row sums of H_raw as component_scale.
  4. Create W_scaled and H_profile using the equations above.
  5. Confirm that every row of H_profile sums to 1 and that the reconstruction has not changed.
NoteSolution

4.6 Exercise 5. Interpret the sample scores

Starting objects: expr, group, W_scaled, H_profile

Goal: Identify the dominant fitted component for each sample and give the arbitrary component numbers meaningful names.

Because each row of H_profile sums to 1, the entries in one row of W_scaled can be converted into within-sample fractions:

\[ q_{ir}=\frac{W^{*}_{ir}}{\sum_s W^{*}_{is}}. \]

The largest fraction identifies the dominant component, while the full row shows whether a sample is strongly dominated by one component or contains substantial contributions from several components.

The Adjusted Rand Index (ARI) compares two partitions while accounting for agreement expected by chance. An ARI of 1 indicates identical partitions. A value near 0 indicates little agreement beyond chance.

Task.

  1. Find each sample’s dominant component.
  2. Cross-tabulate the dominant components against group and calculate the ARI.
  3. Use the cross-tabulation to associate each fitted component with ALL-B-cell, ALL-T-cell, or AML.
  4. Reorder the factors into that biological order and store them as W_named and H_named.
  5. Store the within-sample fractions as sample_fractions.
  6. Find the sample with the smallest largest fraction and store its identifier as mixed_sample.
Important

The known labels are used here only to name and evaluate components after fitting. They were not used to choose genes, select the rank, or fit the final model.

4.7 Exercise 6. Reconstruct one sample and the full matrix

Starting objects: X, expr, gene_names, W_named, H_named, mixed_sample

Goal: Connect the fitted factors directly to reconstructed gene expression.

For sample \(i\) and gene \(j\),

\[ \widehat X_{ij} = \sum_{r=1}^{3}W^{*}_{ir}H^{*}_{rj}. \]

Each term is the contribution of one component. Adding the three component contributions produces the reconstructed sample.

Task.

  1. For mixed_sample, multiply each row of H_named by the matching entry in that sample’s row of W_named.
  2. Store the resulting component-by-gene matrix as sample_contributions.
  3. Sum its rows to obtain sample_reconstruction.
  4. Construct the full reconstruction X_hat and confirm that its row for mixed_sample equals sample_reconstruction.
  5. Store X - X_hat as residual and calculate the overall RMSE.
  6. Identify the eight genes with the largest mean absolute residual.

import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(6.5, 5.5))
for label, colour in group_colours.items():

        W_named.loc[selected, "AML"],

The score plot shows which samples carry the two displayed expression programs. AML samples generally extend along the AML axis and B-cell ALL samples along the B-cell axis. T-cell ALL samples lie closer to the origin because their strongest scores belong to the third, undisplayed component.

The loading plot explains what creates those sample directions. Genes near the AML axis contribute mainly to the AML profile, and genes near the B-cell axis contribute mainly to the B-cell profile. A gene far from both axes contributes to both profiles and therefore helps reconstruct both groups without separating them strongly.

Together, the plots connect the two sides of the factorization: W_named identifies the samples carrying each program, while H_named identifies the genes defining that program.
